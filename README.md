# AI-Chatbot_projectrepo
🧠 AI Chatbot – Smart, Interactive & Responsive This project demonstrates how to build a fully functional AI-powered chatbot using HTML, CSS, and JavaScript. The chatbot is designed to provide instant answers to user queries, making it a great foundation for virtual assistants, help desk bots, or learning tools.

✨ Features ⚡ AI-Powered Conversations – Ask any question and get intelligent, real-time responses.

🖼️ Image Upload Support – Share images directly in the chat.

😊 Emoji Picker – Easily express yourself with a built-in emoji selector.

📱 Responsive Design – Use it seamlessly across desktop and mobile devices.

💬 Clean & Modern UI – Smooth animations and an intuitive interface.
